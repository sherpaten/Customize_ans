# Service E-Commerce Web Application (Vite + React + Tailwind CSS)

Complete project directory with modular components and separate style files (`navbar.css`, `footer.css`, `home.css`, `about.css`, `designs.css`, `gallery.css`, `contact.css`, `global.css`).

## How to Run in VS Code
1. Extract the downloaded ZIP file.
2. Open the folder in VS Code.
3. Open terminal and run `npm install` and `npm run dev`.
